# Solicitudes de comentarios (RFC)

Objetivo: evaluar cambios relevantes antes de comprometer producto, arquitectura o política. Responsable: Equipo MotoCare

Estados: Propuesto, En revisión, Aprobado, Rechazado o Implementado. Un RFC incluye problema, contexto, propuesta, alternativas, impactos funcional/técnico/legal, riesgos, decisión y pendientes. La implementación no implica aprobación; la decisión debe quedar explícita.
