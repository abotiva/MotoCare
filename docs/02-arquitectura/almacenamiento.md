# Almacenamiento

**Estado:** En revisión · **Responsable:** Equipo MotoCare

Supabase Storage conserva activos públicos y documentos privados. El código usa `motocare-public`; las migraciones también definen políticas para documentos y archivos de rutas.

Los soportes sensibles deben ser privados y entregarse con autorización o URL firmada. Deben validarse tamaño, MIME, expiración, borrado y permisos.
