# Checklist de publicación en Google Play

**Estado:** Borrador; no acredita cumplimiento · **Responsable:** Equipo MotoCare

- [ ] Compilación Release reproducible.
- [ ] Firma y custodia de claves verificadas.
- [ ] Archivo AAB generado y probado.
- [ ] Permisos mínimos declarados y justificados.
- [ ] Política de privacidad revisada y publicada.
- [ ] Eliminación de cuenta disponible y verificada.
- [ ] Registro, login y recuperación probados.
- [ ] Notificaciones y permisos probados.
- [ ] Mantenimiento, historial y recordatorios probados.
- [ ] Tamaños de pantalla y versiones Android objetivo probados.
- [ ] Comportamiento sin conexión probado cuando aplique.
- [ ] Textos, accesibilidad y recursos revisados.
- [ ] VersionName/versionCode y notas validados.
- [ ] Data safety, contenido, audiencia y formularios de Play Console revisados.

> Pendiente de definición: empaquetado móvil actual; el repositorio inspeccionado es una SPA web.
