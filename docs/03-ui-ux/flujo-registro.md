# Flujo de registro

**Estado:** Borrador · **Responsable:** Equipo MotoCare

- [ ] Acepto los [Términos y Condiciones](../04-legal/terminos-condiciones.md).
- [ ] He leído la [Política de Privacidad](../04-legal/politica-privacidad.md).

El botón permanece deshabilitado hasta ambas aceptaciones. El sistema registra usuario, documento, versión y fecha/hora del servidor, y solicita nuevamente el consentimiento cuando una versión publicada lo requiera. La infraestructura está implementada; las versiones actuales siguen siendo borradores no publicables.

Casos especiales: fallo al abrir documentos, cambio de versión durante el registro, reintento y registro parcial. La operación deberá ser auditable y consistente.
