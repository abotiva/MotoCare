# Flujo de mantenimiento

**Estado:** En revisión · **Responsable:** Equipo MotoCare

Desde una moto se registra fecha, kilometraje, tipo, notas y costos disponibles. El historial se ordena cronológicamente y los recordatorios dependen de fecha o kilometraje.

Se debe impedir asociar datos a motos ajenas, validar coherencia temporal y diferenciar realizados de pendientes.
