# Flujo de garaje

**Estado:** En revisión · **Responsable:** Equipo MotoCare

El usuario consulta sus motos, crea o edita una con identificación y kilometraje, selecciona la principal y accede a hoja de vida, mantenimientos, programados y documentos.

Validar propiedad mediante RLS, datos obligatorios y kilometraje no regresivo. La eliminación y sus efectos requieren definición explícita.
