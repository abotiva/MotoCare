# Flujo de rutas

**Estado:** Borrador · **Responsable:** Equipo MotoCare

El código permite crear, editar, consultar y asociar rutas a motos, mapas y estados. Rutas no forman parte del lanzamiento Free aprobado.

El acceso debe alinearse con licencias y [RFC-002](../rfc/RFC-002-Rutas.md). No presentar compra o uso Premium como disponible antes de una decisión de release.
