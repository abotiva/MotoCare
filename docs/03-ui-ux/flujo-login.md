# Flujo de inicio de sesión

**Estado:** En revisión · **Responsable:** Equipo MotoCare

El usuario abre `/login`, ingresa correo y contraseña y Supabase valida las credenciales. Una sesión válida conduce al área protegida; un error se muestra sin revelar información sensible.

Deben existir carga, bloqueo de doble envío, recuperación de contraseña y navegación accesible. La recuperación requiere validación E2E.
